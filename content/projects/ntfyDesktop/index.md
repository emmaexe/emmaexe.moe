Ntfy Desktop is a desktop client for [ntfy](https://github.com/binwiederhier/ntfy).

It allows you to subscribe to topics from any ntfy server and recieve notifications natively on the desktop.

It is build on C++ and uses Qt/KDE Frameworks and libcURL.
